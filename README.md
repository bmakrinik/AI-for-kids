# AI for Kids

Hands-on AI activities for parents and children (roughly ages 4–8). No coding experience required.

The aim is not to teach kids to use AI instead of thinking. It's to help them discover what AI can do, how to ask good questions, how to improve results, and when to question its answers.

## Activities

| # | Activity | Time | What kids learn |
|---|---|---|---|
| 1 | [Magical Drawing World](task-01-magical-drawing/README.md) | 20–40 min | Prompting, iteration, creative control |
| 2 | [Monster Guess Who](task-02-monster-guess-who/README.md) | 15–30 min | Asking questions, classification, reasoning, speech interaction |
| 3 | [Monster Platform Adventure](task-03-monster-platform-game/README.md) | 45–90 min | Prompting, game design, visual iteration, debugging |

## Getting started

Start with Task 1 if your child enjoys drawing, or Task 2 if they enjoy games. Each task has materials, exact steps, sample prompts, troubleshooting, and conversation starters.

**Adult supervision:** A parent should handle account setup, image uploads, and microphone permissions. Avoid uploading identifying details, school information, or photos of other children without permission. AI can make mistakes; encourage children to notice and correct them.

## How to contribute

Add activities in numbered folders, each with a README containing: age range, duration, materials, setup, step-by-step instructions, example prompts, learning objectives, and safety notes.
